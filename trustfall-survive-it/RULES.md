# TRUSTFALL rules

## In scope

- Fictional challenge profiles only
- The documented request JSON contract
- The assigned challenge instance
- Synthetic data
- Attack mechanisms taught in Fool It and Control It

## Out of scope

- Real company systems or data
- Real credentials or participant personal data
- Attacks on external services
- Network scanning, denial of service, persistence, or host commands
- Editing opponent files
- Real URLs or data
- Credential extraction or sharing API keys

## Attack submission

Submit exactly five attacks with at least three distinct valid categories. Cosmetic rephrases count as duplicates. Attacks must be purposeful, reproducible, and within the fictional request contract.

## API keys

Use environment variables only. Never submit `.env`, print a key, place a key in source, or paste a key into an attack. Mock mode requires no key and is sufficient for the challenge.

## Fair play

Operate only on the assigned copy. Do not modify an opponent's files or run host-level commands. Report observed behavior and the stated success condition; do not give the defending team root-cause or patch instructions in a breach report.
